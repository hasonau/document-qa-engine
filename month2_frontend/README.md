# Document Assistant — Frontend (Month 2 Day 8)

React chat UI for the RAG API. Assistant replies are mocked for now.

## Run

```bash
cd month2_frontend
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

> Note: this repo path contains `&`, which breaks Windows `vite.cmd` shims. Scripts call Vite via `node` instead.
